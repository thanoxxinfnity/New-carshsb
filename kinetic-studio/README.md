# Kinetic Studio

An original keyframe-animation / motion-graphics editor that runs on Linux (and anywhere with a modern browser). No install, no dependencies: `./run.sh`.

**Features:** vector shapes (rect, ellipse, star/polygon), smooth bezier pen tool, text, image import, layers with reorder/duplicate/trim, keyframes on position, size, rotation, opacity and blur, 6 easing curves, 16 blend modes, gradients, strokes, undo/redo, project save/open (JSON), WebM export.

**Shortcuts:** V select · R rect · E ellipse · S star · P pen · T text · I image · Space play · K key all props · ←/→ step frame · Ctrl+Z/Y · Ctrl+D · Delete.
